# PROJECT ARCHITECTURE: ColorBox - Página de Vendas

## 1. CONTEXT & PROBLEM

Mães e professoras de crianças entre 3-10 anos buscam atividades criativas para entreter seus filhos, mas cadernos físicos são caros, acabam rápido e não têm variedade. Não existe uma solução digital completa com personagens populares (Frozen, Barbie, Peppa Pig, Moana, Disney) por preço acessível e entrega imediata. Isso gera frustração e gasto elevado para as famílias.

## 2. PROPOSED SOLUTION

ColorBox é uma landing page de alto impacto para um produto digital vendido na Hotmart: 30 cadernos para colorir em PDF com personagens populares (Frozen, Barbie, Peppa Pig, Moana, Turma da Mônica, Lol Surprise, Arco-íris, entre outros). Preço único de R$37. Entrega instantânea via Hotmart Club. Garantia de 7 dias. A página deve converter tráfego pago (Meta Ads) com headline emocional, provas sociais, seção de personagens, CTA para o checkout Hotmart e elementos de urgência/escassez.

## 3. FUNCTIONAL REQUIREMENTS

- Landing Page

Seção Hero com headline emocional e CTA para checkout Hotmart | Seção de personagens (grid visual com os 30 cadernos) | Prova social com depoimentos | Seção de benefícios do produto | Contador de urgência/escassez | Seção de garantia 7 dias | FAQ | Footer com link de compra Hotmart | Pixel Meta Ads integrado | Botão flutuante de compra no mobile

## 4. USER PERSONAS

**Visitante/Lead** — Mãe ou professora que chega pelo tráfego pago (Meta Ads), visualiza a página e decide comprar.

**Comprador** — Clica no CTA e é redirecionado ao checkout da Hotmart para concluir a compra de R$37.

**Afiliado (futuro)** — Pessoa que divulga o link de afiliação e recebe comissão por venda via Hotmart.

## 5. TECHNICAL STACK

- React
- Tailwind CSS
- Vercel

**Referências:** Hotmart Pages (referência de layout para produtos digitais brasileiros) | Páginas de produtos infantis com cores vibrantes, personagens em destaque, botões grandes e copy emocional voltada para mães. Design leve, colorido e confiável.

## 6. DESIGN LANGUAGE

Página de vendas estilo Hotmart — cores vibrantes (rosa, roxo, laranja), tipografia bold, imagens de personagens infantis populares (Frozen, Barbie, Peppa Pig), botões grandes de CTA em verde/laranja com texto direto 'QUERO AGORA', selos de garantia e confiança, depoimentos com fotos reais, layout 100% responsivo para mobile-first (público usa celular).
